# 5. Модули (аналог джокеров)

Игрок имеет **5 слотов** под пассивные модули. Порядок слотов важен (см. босс «Глушитель» — отключает крайний левый).

## Категории

| Код | Категория | Файл | Кол-во |
|---|---|---|---|
| `VAL` | Числовые модификаторы (Flat Data & Mult) | [01-value.md](01-value.md) | 9 |
| `SCL` | Масштабируемые (Scaling Engines) | [02-scaling.md](02-scaling.md) | 6 |
| `RUL` | Поле, каскады и аккорды (Rule Breakers & Retriggers) | [03-rule-breakers.md](03-rule-breakers.md) | 8 |
| `HAZ` | Риск, броня и подрыв (Hull & Hazard) | [04-hazard.md](04-hazard.md) | 7 |
| `ECO` | Экономика и ресурсы (Bits & Utility) | [05-economy.md](05-economy.md) | 5 |
| `LEG` | Экзотические и легендарные (Game Changers) | [06-legendary.md](06-legendary.md) | 3 |

## Формат записи

Каждая категория — таблица с колонками:

| Колонка | Описание |
|---|---|
| ID | `MOD-<CAT>-NN`, стабильный, используется в коде |
| Название | RU «Название» (EN Name) |
| Триггер | из [глоссария](../../glossary.md#триггеры) |
| Эффект | точная формулировка с числами |

Новый модуль: [шаблон](../../templates/module.md) → строка в таблицу категории → обновить счётчик выше.
