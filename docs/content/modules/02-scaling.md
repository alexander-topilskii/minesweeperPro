# Масштабируемые модули (Scaling Engines) — `SCL`

| ID | Название | Триггер | Эффект |
|---|---|---|---|
| MOD-SCL-01 | «Бортовой самописец» (Black Box) | `onFlag`, `onMineHit` | $+0.1\times$ Mult за каждую корректно помеченную мину. Сбрасывается при подрыве. |
| MOD-SCL-02 | «Счетчик Гейгера» (Geiger Counter) | `onReveal` | $+1$ Mult за каждый клик по клетке, граничащей с закрытой миной. Накапливается до конца раунда. |
| MOD-SCL-03 | «Архиватор» (Deep Storage) | `onSectorEnd` | Навсегда $+2$ к базовой Data за каждый оставшийся клик в конце сектора. |
| MOD-SCL-04 | «Анализ Монте-Карло» (Monte Carlo) | `onCascade` | Постоянные $+0.05\times$ Mult за каждый каскад нулей. Не сбрасывается между раундами. |
| MOD-SCL-05 | «Следопыт» (Flag Bearer) | `onFlag` | $+2$ Data за каждый флаг в текущей сессии (максимум $+100$). |
| MOD-SCL-06 | «Контролируемый пал» (Controlled Burn) | `onHullBreak` | При уничтожении щита Mult утраивается до конца раунда. |
