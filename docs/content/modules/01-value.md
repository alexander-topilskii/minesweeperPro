# Числовые модификаторы (Flat Data & Mult) — `VAL`

| ID | Название | Триггер | Эффект |
|---|---|---|---|
| MOD-VAL-01 | «Бинарный код» (Binary Core) | `onReveal` | Цифры 1 дают $+15$ Data; цифры 2 дают $+4$ Mult. |
| MOD-VAL-02 | «Четный фронт» (Even Split) | `onReveal` | Каждая четная цифра (2, 4, 6, 8) дает $+5$ Mult. |
| MOD-VAL-03 | «Нечетный импульс» (Odd Charge) | `onReveal` | Каждая нечетная цифра (1, 3, 5, 7) дает $+25$ Data. |
| MOD-VAL-04 | «Троичный триггер» (Triangulation) | `onReveal` | Цифра 3 дает $+10$ Mult, если у нее уже открыты минимум два соседа. |
| MOD-VAL-05 | «Критическая масса» (High Roller) | `onReveal` | Цифры 4 и выше дают $+50$ Data и $+8$ Mult. |
| MOD-VAL-06 | «Одинокий пик» (Deadlock 8) | `onReveal` | Цифра 8 дает $+200$ Data и $\times5$ к итоговому счету хода. |
| MOD-VAL-07 | «Стрит-детекция» (Sequence Run) | `onReveal` | 3 клика подряд открывают цифры по возрастанию (1 → 2 → 3) → ход получает $\times3$ Mult. |
| MOD-VAL-08 | «Тройной интеграл» (Triple Integral) | `onReveal` | Цифра 3 удваивает текущий общий множитель раунда. |
| MOD-VAL-09 | «Экстремум» (Extremum) | `onReveal` | Цифры 5+ навсегда увеличивают множитель раунда на $+3$ Mult при каждом открытии. |
