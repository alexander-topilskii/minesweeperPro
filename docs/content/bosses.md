# 7. Боссы / Аномалии (Boss Anomalies)

Активируются на 3-м этапе каждого сектора и ломают стандартные алгоритмы решения.

| ID | Название | Эффект |
|---|---|---|
| BOSS-01 | Ионная буря (The Static) | Все цифры 1 и 2 скрыты за помехами `?`. |
| BOSS-02 | Тектонический сдвиг | Каждые 3 клика закрытые мины смещаются на одну клетку по часовой стрелке. |
| BOSS-03 | Гексагональная мутация | Поле переключается на шестиугольную сетку (6 соседей). |
| BOSS-04 | Слепой радар | Цифры видны 1.5 с, затем клетка выглядит пустой. |
| BOSS-05 | Глушитель (Jammer) | Отключает крайний левый модуль игрока. |

Новый босс: [шаблон](../templates/boss.md).
