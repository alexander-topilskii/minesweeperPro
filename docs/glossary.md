# Глоссарий

## Термины

| Термин | Описание |
|---|---|
| **Data** | Синие очки — база хода. Значение цифры (1–8) или фиксированная награда за 0. |
| **Mult** | Красный множитель. Аддитивные бонусы пишутся `+N Mult`, мультипликативные — `×N Mult`. |
| **Счёт хода** | `(Data + бонусы) × Mult` для одного действия игрока (включая весь каскад). |
| **Clicks / Батарея** | Лимит активных нажатий на раунд. |
| **Hull HP** | Прочность корпуса. Мина = −1 HP. |
| **Bits** | Валюта для магазина. |
| **Комбо** | Серия безопасных кликов подряд. Сбрасывается при подрыве. |
| **Каскад** | Автоматическое открытие области при вскрытии нуля. |
| **Аккорд (Chording)** | Клик по открытой цифре с верным числом флагов вокруг — открывает остальных соседей. |
| **Retrigger** | Повторное срабатывание эффекта. |
| **Раунд / Этап** | Одно поле. |
| **Сектор (Глубина, Ante)** | 3 этапа: стандартный, глубокий, босс. |
| **Забег** | 8 секторов. |

## Триггеры

Используются в колонке «Триггер» каталогов контента и как имена событий в коде.

| Триггер | Когда срабатывает |
|---|---|
| `onReveal` | Открыта безопасная клетка (вручную, каскадом или аккордом). |
| `onCascade` | Завершён каскад нулей. |
| `onChord` | Выполнен аккорд. |
| `onFlag` | Поставлен флаг. |
| `onMineHit` | Клик по мине. |
| `onHullBreak` | Потерян щит / HP. |
| `onTurnEnd` | Подсчёт счёта хода. |
| `onRoundEnd` | Завершение раунда. |
| `onSectorEnd` | Завершение сектора. |
| `onFieldGen` | Генерация поля. |
| `passive` | Постоянный эффект / изменение правил. |
