# 8. Аудиовизуальный стиль и UX ("Game Juice")

## Эстетика

Терминал полевого инженера 1980-х: монохромный или янтарный CRT-дисплей, кинематографичные шумы сканирования, микросхемы и механические переключатели.

## Фидбек набора очков

| Событие | Фидбек |
|---|---|
| Каскад | Возрастающее по тональности арпеджио, имитирующее цепную реакцию. |
| Начисление очков | Механическая «накрутка» счётчика с треском счётчика Гейгера. |
| Срабатывание модуля | Плата модуля вспыхивает + релейный щелчок. |
