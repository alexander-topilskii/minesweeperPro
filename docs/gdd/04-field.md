# 4. Поле и управление

| Действие | Управление | Эффект |
|---|---|---|
| Сканирование (Reveal) | ЛКМ | Открывает клетку. Тратит 1 клик. Мина — урон корпусу. |
| Маркировка (Flag) | ПКМ | Ставит метку мины. Не тратит клик. |
| Аккорд (Chording) | Клик по открытой цифре | Если вокруг выставлено верное число флагов — открывает остальных соседей одним действием. |
